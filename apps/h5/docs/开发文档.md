## 1. 项目定位

H5 是 monorepo `itzy-app` 下的移动端 Web 子包（`@itzy-app/h5`），用 **React 18 + TypeScript + Vite** 构建，部署在 **GitHub Pages**（`base: /itzy-app/`）。

除 ITZY 粉丝向核心能力（首页、行程、娃娃图鉴、应援、票根等）外，仓库内还集成了多组 **设计站镜像 / 动效实验**（Stagecrew、Fácil、Noth、Waka Waka 等），通过 `/menu` 统一索引。

| 类型 | 说明 |
|------|------|
| **ITZY 产品向** | 查场次、认 WDZY/TWINZY、练应援、生成票根、成员视觉 |
| **NewNew 视觉壳** | Oh Ira 气质首页 + 固定顶栏二级页（XKM Cover Nav） |
| **App Shell** | 冰蓝 Y2K Lab 渐变 + 顶栏，承载 Gallery / Portfolio 等 |
| **Mirror / Lab** | 第三方站点还原、WebGL/物理/票根实验、可复用 UI 组件库 |

产品级 PRD / 首页 UI 规范见仓库根目录：

- [`md/ITZY官网产品设计文档.md`](../../../md/ITZY官网产品设计文档.md)
- [`md/ITZY官网首页UI设计.md`](../../../md/ITZY官网首页UI设计.md)

## 2. 技术栈

| 类别 | 选型 |
|------|------|
| 框架 | React 18、react-router-dom 6 |
| 构建 | Vite 4、`@vitejs/plugin-react` |
| 动效 | GSAP、Framer Motion、Lenis（平滑滚动） |
| 3D / 特效 | Three.js、Matter.js、`@paper-design/shaders-react` |
| 样式 | 页面级 CSS / 少量 SCSS（`LabStyle.scss`），无全局 UI 框架 |
| PWA | `vite-plugin-pwa` + `workbox-window`（`OfflineBadge`） |
| 包管理 | pnpm workspace，`packageManager: pnpm@8.15.9` |

**数据请求**：`src/services/request.ts`  
- `VITE_API_BASE` 默认 `http://127.0.0.1:3000`  
- `USE_LIVE_API`（`config/dataSource`）为 false 时走 `mock-data/mockApi`

## 3. UI 体系与样式分层

H5 **没有单一全局 Design System**，而是按 **Layout / 页面家族** 挂载不同 CSS 变量与背景。开发新页时先确定挂在哪个壳下，避免混用 `body:has(...)` 背景规则。

### 3.1 全局默认（`src/index.css`）

| Token | 值 | 用途 |
|-------|-----|------|
| `--text` | `#6b6375` | 正文 |
| `--text-h` | `#08060d` | 标题 |
| `--bg` | `#fff` | 卡片底 |
| `--accent` | `#aa3bff` | 实验室强调色 |
| `body` 背景 | `#eaf7ff` | 与 Lab 冰蓝渐变衔接 |

根节点 `#root` 全宽、`min-height: 100svh`；移动端基准字号 16px（≤1024px）。

### 3.2 Lab / App Shell（`src/styles/lab-global.css` + `layouts/AppLayout.css`）

- **`.h5-shell`**：多层 radial + linear 冰蓝渐变（与 `LabStylePage` 的 `.y2k-page` 一致）。
- **玻璃卡片**：`.home .hero`、`.schedules-card`、`.gswiper` 等统一 `border-radius: 16px`、半透白底与蓝色阴影。
- **导航**：`.h5-nav` 内链激活态为粉橙渐变 pill（`#ff6aa8` → `#ffcc6a`）。

**路由**：`/gallery`、`/gallery/:id`、`/lab-style`、`/portfolio`。

### 3.3 NewNew 首页（`newnew/newnew.css` + `new-home/new-home.css` + `XkmPage.css`）

**默认首页** `/` → `NewNewPage` → `NewHomePage`（`overlayCacheKey="newnew"`）。

| Token / 区域 | 值 / 行为 |
|--------------|-----------|
| `--newnew-bg` | `#60646d` |
| `--newnew-surface` | `#d9d9d9` |
| `--newnew-panel` | `#ef97d1`（粉面板） |
| `--newnew-accent` | `#1733ff` |
| `--newnew-accent-2` | `#ff2a22` |
| XKM 壳 | 灰底 `#e4e4e4`、白顶栏格子导航 `xkm-coverNav` |
| 加载遮罩 | 文案 `itzy all in us` 打字机；SPA 返回可跳过（`overlaySeenKeys`） |
| 动效 | Lenis 滚动、`NewHomeFallCanvas` 下落相册、`NewHomeRefractionCanvas` WebGL 折射 |
| 入口 | 票根组件 `NewNewArtworkTicket`、巡演海报资源、链接至 schedules / dolls / cheer 等 |

**展览版首页** `/newnew-exhibit`：`NewNewExhibitHome` + `newnew-exhibit.css`，策展图廊 `ExhibitTile`、`getCuratedExhibitGallery`。

### 3.4 NewNew 二级页壳（`NewNewLayout`）

挂在 `NewNewLayout` 下的页面共享：

| 变量 | 默认 |
|------|------|
| `--newnew-nav-h` | `60px` |
| 顶栏 | `NewNewCoverNav`（fixed），上滑后可 `xkm-coverNav--pinned` 透明无底边 |
| 页面背景 | `var(--newnew-surface)` `#d9d9d9` |
| 过渡 | `NewNewPageTransition` |

**子路由**：`/dolls`、`/poster`、`/poster/preview`、`/game`、`/setlist`、`/schedules`、`/cheer/:slug`、`/unseen`。

### 3.5 行程页 `/schedules`（`SchedulesPage.css`）

- **满屏黑底** `#000`，白字，与 PRD「档案感 + 现场能量」中的暗色列表一致。
- 标题：`uppercase`、粗体、`clamp` 字号；副标 11px 字距加宽。
- 列表行：英文 `场馆 · 城市`，右侧日期；同场馆多天合并区间。
- 数据：`GET /api/schedules`（mock 或 live）。
- 滚动：离开其它页时清理 `html/body` 滚动锁；Lenis 触摸阻尼（见 README 迭代说明）。

### 3.6 娃娃图鉴 `/dolls`（`DollsPage.css`，类名前缀 `unseen-`）

| 阶段 | 样式要点 |
|------|----------|
| **选择门** `.unseen-gate` | 白底编辑风；WDZY / TWINZY 分区；响应式 cover 网格（大屏约 5 列，小屏 3/2 列） |

| **系列角标** | `.unseen-line-label--kr` 红 `#ff5a7a`、 `--jp` 蓝 `#5aa9ff`、 `--sega` 金 `#f4c430` |

| **详情弹窗** | `clamp` 卡片尺寸、`aspect-ratio: 2/3`、`max-height` 限高滚动 |

数据：`src/data/wdzy_twinzy_catalog.json` + `src/data/img/`。

## 4. ITZY 核心功能说明

### 4.1 首页策略（实现现状）

| 路径 | 实现 |
|------|------|
| `/` | NewNew + NewHome：遮罩加载、XKM 导航、主视觉/折射/下落、链到内页 |
| `/newnew-exhibit` | 展览策展首页 + 场次 API 高亮卡片 |
| API | `request` 拉取 schedules 等（mock/live） |

PRD 中的「回归海报 vs 下一场演唱会」切换以后台配置为准；前端已具备海报资源与场次展示能力，具体开关见接口字段与首页组件逻辑。

### 4.2 演唱会日程

- **路由**：`/schedules`（NewNew 壳）。
- **展示**：黑底列表、pill 标签、英文标题、日期区间合并。
- **接口**：`GET /api/schedules`。

### 4.3 娃娃管理（WDZY / TWINZY）

- **路由**：`/dolls`（主图鉴）、`/unseen`（独立世界）。
- **流程**：选择成员/系列门 → 进入拖拽世界 → 点击卡片详情 → `All Dolls` / `Focus` → 「按系列排列」/「打散」。
- **字段**（catalog）：`line`（KR/JP/SEGA）、`size`、`release`、`model`、`jan`、`gridX/gridY` 等。
- **资源**：`public` 与 `src/data/img` 下的立偶图；缺图可用成员 plush 占位。

### 4.4 歌曲应援

- **路由**：`/cheer/:slug`。
- **内容**：按曲目的歌词行 + 应援词 tone（喊词/和声等）分色。
- **扩展**：在 `src/pages/cheer/guides/` 新增 guide 并注册到 `cheerData.ts`。

### 4.5 票根生成

- **路由**：`/poster`、`/poster/preview`。
- **能力**：基于场次与模板槽位 Canvas 出图，可跳转预览。

### 4.6 图鉴 / 作品集（App Shell）

- **Gallery**：`/gallery`、`/gallery/:id`（示例 `local-demo-album`）。
- **Portfolio**、**Lab Style**：实验与展示壳。

### 4.7 小游戏

- **路由**：`/game`（占位，待接入具体玩法）。

## 8. 样式开发约定

1. **先选 Layout**：NewNew 二级页用 `.newnew-shell` 变量；不要在全站改 `body` 背景 unless 该页用 `body:has(.xxx)` 约定。
2. **响应式**：ITZY 页优先 mobile；字号与间距多用 `clamp()`；触控热区 ≥ 44px（应援、导航）。
3. **滚动**：Facil / Noth / People 等页使用 Lenis；离开时在 `useEffect` 清理或依赖 Menu 页的统一清理逻辑。
4. **动效降级**：首页遮罩、打字机等于 `prefers-reduced-motion: reduce` 分支。
5. **系列色**：娃娃 KR/JP/SEGA 三色与 `.unseen-line-label--*` 保持一致，避免硬编码新色。
6. **与 PRD UI 文档对齐**：档案风黑白灰为主；品牌点缀见 `ITZY官网首页UI设计.md` 的 `--accent` 等 token（NewNew 当前实现使用蓝 `#1733ff` / 红 `#ff2a22` / 粉面板，属 Oh Ira 分支调色）。
